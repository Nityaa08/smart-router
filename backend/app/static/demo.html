Python · FastAPI · OpenAI-compatible LLM gateway

Send each prompt to the cheapest model tier that can handle it.

Smart Router sits between an app and its LLMs. Hand-written rules score each prompt in under a millisecond, pick a simple, medium or complex tier, fall back to the next tier if a provider fails, and log what the request would have cost on GPT-4o.

Demo mode. Answers are simulated: no language model is called and no API key is used. The classification, routing, fallback, cost estimate and analytics are the project's real code.

How it works

The gateway speaks the OpenAI chat format, so an app only changes its base URL. No LLM is used to classify: the score comes from length, keywords, code, multi-step and math patterns.

Drop-in APIPOST /v1/chat/completions, plus X-Router-Tier and X-Router-Model headers.
ExplainableEvery decision can be traced to the rules above; /v1/route/explain returns them.
ResilientA failing provider escalates to the next tier, for normal and streamed requests.
TestedUnit tests with fake providers cover routing, fallback, streaming, cache, auth and limits.

Call it like OpenAI

Point any OpenAI client at the gateway. On this public demo the answers are simulated and requests are rate limited.
