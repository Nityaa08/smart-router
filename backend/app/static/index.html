How it works
01
Your app sends a prompt
POST to /v1/chat/completions — same format as the OpenAI API. No SDK changes needed.
02
Classifier scores it instantly
Zero-cost heuristics analyze token count, keywords, and code patterns in <1ms to assign a complexity tier: simple, medium, or complex.
03
Cheapest capable model answers
Simple queries go to a 1B model. Only genuinely hard prompts reach the expensive one. Every request is logged with cost saved vs GPT-4o.
